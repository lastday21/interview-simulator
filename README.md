# Тренажёр собеседований

Телеграм-бот для подготовки к техническому собеседованию. Пользователь выбирает тему и подтему, отвечает на вопросы, открывает эталонные ответы и отмечает результат. Прогресс хранится в PostgreSQL, временное состояние диалога — в Redis.

## Запуск

1. Создайте `.env` на основе `.env.example` и укажите действующий `BOT_TOKEN`.
2. Запустите приложение:

```powershell
docker compose up -d --build
```

3. Проверьте состояние контейнеров:

```powershell
docker compose ps
.\scripts\smoke.ps1
```

При запуске контейнера бота последовательно применяются миграции базы данных, загружается каталог вопросов и запускается сам бот. PostgreSQL и Redis доступны с компьютера только через адрес `127.0.0.1` и отдельные порты из `.env`, поэтому они не занимают порт Telegram-бота. Сам бот не открывает сетевой порт: он получает обновления через Telegram.

## Каталог вопросов

Единственный исходный каталог находится в `data/questions.json`. При обычном запуске его содержимое записывается в PostgreSQL. База данных нужна для работы приложения и хранения прогресса, но источником текста вопросов остаётся этот файл.

Проверить файл без подключения к базе данных:

```powershell
poetry run python scripts/import_questions.py --check
```

Загрузить изменения вручную:

```powershell
poetry run python scripts/import_questions.py
```

Если Poetry недоступен как отдельная команда, в уже созданном окружении Windows можно вызвать `.venv\Scripts\python.exe scripts\import_questions.py --check`.

Каждый вопрос содержит:

- `id` — постоянный уникальный идентификатор;
- `источник` — идентификатор записи из раздела `sources`;
- `тема` и `подтема`;
- `вопрос` и `ответ`;
- необязательный признак `is_active`.

Идентификатор существующего вопроса нельзя менять при правке текста или перестановке строк: по нему сохраняется пользовательская статистика. Новому вопросу нужен новый идентификатор. Порядок строк задаёт порядок вопросов внутри подтемы.

Вопросы, которых больше нет в файле, при обычной загрузке выключаются, но остаются в базе вместе со связанной статистикой. Полное удаление выполняется только явно:

```powershell
poetry run python scripts/import_questions.py --purge-missing
```

Эта команда безвозвратно удаляет из базы отсутствующие вопросы, связанные с ними ответы и результаты, а также опустевшие темы и подтемы. Для повседневного обновления каталога она не нужна.

В каталог следует добавлять только оригинальные материалы или материалы с лицензией, разрешающей распространение. Часть вопросов основана на открытом репозитории [yakimka/python_interview_questions](https://github.com/yakimka/python_interview_questions) и отредактирована для формата тренажёра; условия лицензии MIT приведены в `THIRD_PARTY_NOTICES.md`. Новые разделы SQL, HTTP, серверной разработки, Git, Docker и карьерного интервью написаны специально для этого проекта.

Техническая проверка структуры каталога выполняется автоматически. Смысловая проверка формулировок и ответов ведётся отдельно: наличие вопроса в каталоге само по себе не означает, что его содержание уже прошло редактуру.
